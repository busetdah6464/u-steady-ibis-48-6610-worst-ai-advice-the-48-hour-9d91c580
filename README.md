# Worst AI Advice: The 48-Hour Tight Line Open

Entry for [Worst AI Advice](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) on make.fun.

One line of deliberately terrible advice in an AI assistant's confident,
tidy voice: delete your operating system to save battery. It is specific
enough to follow, bad enough to regret, and the punchline — a phone that
never turns on lasts forever — is technically true, which is exactly how
the worst AI advice sounds.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
